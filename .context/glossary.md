# Continuum Glossary

- **Continuum**: Mac-first authoring app for writing and editing Diario drafts.
- **Diario**: Diario de Ocurrencias, the web backend, admin editor, and public reader.
- **Ocurrencia**: A self-contained thought, note, or fragment that may remain a draft or become a published note.
- **Note**: A local Continuum record containing metadata, structured draft data, TipTap JSON, text indexes, and sync state.
- **Draft**: A saved but unpublished note version.
- **Published Note**: A note made public through Diario's explicit lifecycle command.
- **StructuredNoteDraft**: Canonical structured draft contract shared by Continuum and Diario.
- **StructuredParagraph**: Structured paragraph block with stable identity and editorial metadata.
- **Stable ID**: Persistent identifier that must survive editing operations and sync.
- **Block ID**: Identifier attached to a structured block such as a paragraph or aphorism.
- **TipTap**: React editor framework used to build the structured editor.
- **ProseMirror**: Document model and transaction engine underneath TipTap.
- **TipTap JSON**: ProseMirror document serialized as JSON for editor state.
- **Reader**: Public rendering surface in Diario.
- **Admin Editor**: Diario's web editor for emergency or secondary editing.
- **Aphorism**: Numbered/editorial paragraph form with stable identity and reader semantics.
- **Aphorism Number**: Visible numbering for aphorism blocks, rendered with oldstyle numerals.
- **Citation**: Editorial citation relationship represented in the structured document.
- **Reference**: Bibliographic/source entity that can be associated with text.
- **ReferenceInsert**: Inline inserted reference text or source marker inside the editor.
- **Superscript**: Inline marker used to connect text to citation/reference metadata.
- **Long Quote**: Block-level citation form with distinct typography and attribution behavior.
- **Inline Math**: TeX/math atom inside text; not plain editable text for correction.
- **TeX**: Math notation entered in the editor and rendered as inline math.
- **Written Date**: Editorial date attached to a note, distinct from database timestamps.
- **Created At**: Technical timestamp for note creation.
- **Updated At**: Technical timestamp for last local or remote update.
- **Plain Text**: Search/index text derived from structured content.
- **Excerpt**: Short display preview derived from plain text.
- **SQLite Repository**: Local persistence layer for notes, revisions, queue, and conflicts.
- **Migration**: Versioned SQLite schema change.
- **Revision**: Local historical snapshot or remote version marker.
- **Remote Revision**: Diario-side revision used to detect conflicts.
- **Sync Queue**: Persistent queue of local changes awaiting remote sync.
- **DraftSyncEngine**: Background sync loop that pushes and pulls Diario draft state.
- **Conflict**: State where local and remote versions diverged and require explicit resolution.
- **Keep Local**: Conflict action that preserves and re-pushes the local version.
- **Use Remote**: Conflict action that replaces local draft content with remote content.
- **Duplicate Local**: Conflict action that preserves local work as a separate note.
- **Trash**: Reversible local note state for removed notes.
- **Emergency Draft**: Recovery file for the active note outside normal SQLite writes.
- **AI Correction**: OpenAI-backed conservative spelling/grammar correction feature.
- **CorrectionSuggestion**: A suggested textual replacement generated by local diffing.
- **SelectionPlainTextMap**: Mapping from selected plain text offsets to ProseMirror positions.
- **Stale Suggestion**: Suggestion whose original text no longer matches the document.
- **Unsafe Suggestion**: Suggestion that cannot be safely mapped to document structure.
- **Applied Suggestion**: Suggestion already committed to the editor via transaction.
- **Decoration.inline**: ProseMirror read-only highlight overlay that does not alter document JSON.
- **Lexical Lookup**: Synonym, antonym, and etymology lookup for selected words.
- **Lexical Provider**: Replaceable backend for lexical lookup, such as RAE or future AI.
- **Provider Chain**: Ordered set of lexical providers that can be combined or swapped.
- **Tauri Store**: Local preference storage; not secure for release secrets.
- **Stronghold**: Tauri plugin option for encrypted local secret storage.
- **OS Keychain**: Native operating-system credential storage.
- **CSP**: Content-Security-Policy for the Tauri WebView.
- **Golden Fixture**: Stable sample contract used to prove cross-app compatibility.
